## 🚀 Overview

**Support AI** is a **full-stack SaaS application** built using **Next.js**, **MongoDB**, **Gemini AI**, and **Scalekit Authentication**.

It allows multiple organizations to create and manage their own AI-powered customer support chatbot, customize it, and embed it into any website using a lightweight JavaScript widget.

Whether you're a startup, SaaS company, freelancer, or agency, Support AI helps automate customer support while providing a clean dashboard to manage chatbot settings.

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/support-ai.git
```

Go to the project

```bash
cd support-ai
```

Install dependencies

```bash
npm install
```

Create a `.env.local`

```env
MONGODB_URI=

SCALEKIT_CLIENT_ID=
SCALEKIT_CLIENT_SECRET=

GEMINI_API_KEY=

NEXT_PUBLIC_APP_URL=
```

Run the project

```bash
npm run dev
```

---

# 🌍 Environment Variables

| Variable | Description |
|----------|-------------|
| MONGODB_URI | MongoDB Connection |
| GEMINI_API_KEY | Google Gemini API |
| SCALEKIT_CLIENT_ID | Scalekit Client ID |
| SCALEKIT_CLIENT_SECRET | Scalekit Secret |
| NEXT_PUBLIC_APP_URL | Application URL |
